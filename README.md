# BMI Calculator – C++

A beginner-level C++ project that calculates Body Mass Index (BMI) based on the user's height and weight.

## Features

* Takes height and weight as user input
* Calculates BMI
* Displays the calculated BMI
* Shows the corresponding BMI category

## Technologies Used

* C++
* Basic programming concepts
* Conditional statements
* User input/output

## Purpose

This project was created as part of my early Software Engineering studies to practice basic C++ programming and problem-solving.

## How to Run

1. Download or clone this repository.
2. Open `FINAL BMI.cpp` in a C++ IDE or compiler.
3. Compile and run the program.
4. Enter the required height and weight values.
